# Парсер вакансий для копирайтеров

Раз в день собирает посты из публичных телеграм-каналов с вакансиями, отбирает до пяти вакансий
по текстам и контенту на удалёнке и отправляет их одним сообщением в группу через бота.

## Как работает

1. `collector.py` читает посты за 3 дня через веб-превью `t.me/s/<канал>` (аккаунт Telegram не нужен),
   срезает рекламные подвалы и режет дайджесты на отдельные вакансии.
2. `selector.py` решает, подходит ли вакансия. Сейчас по словам из `keywords.txt`:
   тема (тексты, редактура, контент, сценарии) + удалёнка, без иностранного языка, курсов, схем, отзывов
   и случаев, когда платит соискатель. В каналах целиком про тексты (`config.TEXT_CHANNELS`)
   слово «удалёнка» не обязательно, отсекается только явный офис или гибрид.
3. `dedup.py` убирает одну и ту же вакансию из разных каналов (похожий текст или одинаковый конкретный заголовок)
   и то, что уже отправлялось за 30 дней (`sent.json`).
4. `main.py` берёт до пяти, не больше двух из одного канала: сначала текстовые роли, потом SMM и контент;
   внутри группы сначала с оплатой за последние 2 дня, потом по свежести. Если вакансий ноль, ничего не отправляет.
   `formatter.py` собирает сообщение «Вакансии на <дату>»: заголовок-ссылка на пост, суть до 280 знаков,
   метки (оплата, формат, опыт), контакт для отклика и предупреждение про оплату обучения.

## Установка

```
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и впишите `BOT_TOKEN` (от @BotFather) и `CHAT_ID`.

Узнать `CHAT_ID`: добавьте бота в группу, напишите там `/start@имя_бота`, запустите `python get_chat_id.py`.

## Запуск

```
python main.py --dry-run           # сообщение в консоль, ничего не отправляется, sent.json не меняется
python main.py --dry-run --debug   # плюс что прошло отбор, что отсеяно и почему, какие дубли
python main.py                     # отправка в группу
```

## Настройка

- Каналы, глубина сбора, число вакансий, порог похожести: `config.py`.
- Слова для отбора: `keywords.txt` (правила в начале файла). После правки проверьте результат через `--dry-run --debug`.
- Нейросеть для отбора: добавить в `selector.py` функцию с тем же входом и выходом, что `check_keywords`,
  и выбрать её в `config.SELECTOR`. Остальной код не меняется.

## Выгрузка постов для анализа

```
python collector.py --days 30 --out выгрузка rueventjob textodromo
```

## Автозапуск

GitHub Actions, файл `.github/workflows/send.yml`: каждый день в 10:00 по Москве (07:00 UTC)
и вручную кнопкой Actions → «Вакансии в чат» → Run workflow. Задача выполняет `python main.py`
и коммитит обновлённый `sent.json` обратно в репозиторий, чтобы не повторяться.

Секреты репозитория (Settings → Secrets and variables → Actions): `BOT_TOKEN`, `CHAT_ID`.
