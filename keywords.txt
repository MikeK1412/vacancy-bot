# Списки слов для отбора вакансий. Файл можно править вручную.
#
# Как устроено:
# - раздел начинается с названия в квадратных скобках, дальше по одному слову или фразе на строку;
# - слово ищется как кусок текста: «копирайт» найдёт и «копирайтер», и «копирайтинг»;
# - слова из 1–3 знаков (b2, c1) ищутся только отдельным словом: «b2» не найдётся в «B2B»;
# - регистр не важен, ё и е считаются одной буквой;
# - строка, которая начинается с решётки, это комментарий.
#
# Вакансия проходит, если:
#   1) есть слово из [тема в заголовке] в заголовке ИЛИ фраза из [тема в тексте] в тексте;
#   2) в заголовке нет слов из [не тема];
#   3) есть слово из [удалёнка]. В каналах целиком про тексты (config.TEXT_CHANNELS) не обязательно;
#   4) нет слов из [не удалёнка], а слова из [офис] есть только вместе с удалёнкой;
#   5) нет слов из [иностранный язык] (кроме строк со словами из [язык не обязателен])
#      и текст вакансии не на иностранном языке;
#   6) нет слов из [мусор];
#   7) для SMM и контент-менеджеров нет слов из [smm: съёмки и выезды];
#   8) нет слов из [очная работа]; требование жить в городе — только вместе с явной удалёнкой;
#   9) если удалёнка не указана, нет жёсткого графика («с 9 до 18», «5/2 с 10:00»; шаблоны в selector.py);
#  10) в заголовке нет слов из [сеньорская позиция].
#
# Порядок в сообщении: сначала [текстовые роли], потом [smm и контент] и прочее;
# внутри группы сначала с оплатой за последние 2 дня, потом по свежести.
